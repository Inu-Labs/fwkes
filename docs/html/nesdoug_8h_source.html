4// Why am I doing so much with a vram_buffer? This is an automated system, which
5// works when the screen is on. You can write to the buffer at any time.
6// During NMI / v-blank, it automatically writes to the PPU.
7// You don't have to worry about timing those writes. And, more importantly,
8// you shouldn't have to turn the screen off...
9// allowing us to make smooth scrolling games.
